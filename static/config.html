1 Pro Tools …

O Prompter abre o Pro Tools junto quando inicia. Abra a sessão da música. O Prompter se conecta sozinho pela biblioteca de scripts do Pro Tools (PTSL): sem driver, sem configuração. Funciona no Pro Tools Intro, Artist, Studio e Ultimate a partir da versão 2022.12.
Pro Tools aberto conectado (PTSL) sessão

2 Músicas e letras …

Cada sessão do Pro Tools é uma música. Ao abrir a sessão, o Prompter lê os áudios dela e transcreve a letra em segundo plano (com tempo palavra por palavra). Se quiser a letra exata, cole a oficial no estúdio: ela é alinhada com o áudio.

3 Transcrição …

A primeira transcrição baixa o modelo (uma vez, ~1,6 GB). Depois roda sem internet, na CPU, em prioridade baixa e só quando o Pro Tools está parado. large-v3-turbo acertou 97% das palavras nos testes; medium 72%; small serve para conferir rápido.
modelo separador de voz

4 Precisão máxima (opcional): MTC …

Sem isto o Prompter já acompanha o Pro Tools com erro de ~0,1 s. Com o MTC (timecode MIDI) a posição vem frame a frame. Precisa do loopMIDI (gratuito, de Tobias Erichsen) e de ligar o gerador de MTC no Pro Tools, uma vez.
loopMIDI instalado porta "Pro Tools MTC" MTC chegando
  • No Pro Tools: Setup › Peripherals › Synchronization → MTC Generator Port = Pro Tools MTC → OK.
  • Window › Transport; no menu View › Transport › Synchronization; deixe o botão Gen MTC aceso.
  • Dê play: o ponto "MTC chegando" fica verde.
