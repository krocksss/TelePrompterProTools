Configuração

Cada item abaixo mostra o estado real agora. O normal é tudo ficar verde sozinho: o Prompter abre o Pro Tools, se conecta e transcreve as músicas que você soltar.

1

Pro Tools

O Prompter abre o Pro Tools junto e se conecta pela biblioteca de scripts dele (PTSL), sem driver e sem configuração. Funciona no Intro, Artist, Studio e Ultimate a partir da versão 2022.12.
Pro Tools aberto conectado sessão
2

Músicas

Solte um MP3 ou WAV em Músicas: ele é transcrito e ganha uma sessão no Pro Tools com um clique. Sessões que você abrir no Pro Tools também entram sozinhas.

3

Transcrição

Roda neste computador, sem internet depois do primeiro download (1,6 GB), em prioridade baixa e nunca enquanto o Pro Tools toca. O modelo padrão acertou 97% das palavras nos testes.
antecipar palavras (s):
modelo de transcrição separador de voz
4

Precisão máxima, opcional

Sem isto o Prompter já acompanha o Pro Tools com erro de cerca de 0,1 s. Com o timecode MIDI (MTC) a posição vem frame a frame. O loopMIDI já foi instalado junto; falta só ligar o gerador no Pro Tools, uma vez.
loopMIDI porta "Pro Tools MTC" timecode chegando
  • No Pro Tools: Setup › Peripherals › Synchronization, MTC Generator Port = Pro Tools MTC, OK.
  • Window › Transport, depois View › Transport › Synchronization, e deixe o botão Gen MTC aceso.
  • Dê play: "timecode chegando" fica verde.
5

No show

O Prompter fica na bandeja, ao lado do relógio. Teclas no teleprompter: F tela cheia, espaço play/stop no Pro Tools, ← → linha na mão, A automático.
